# Changelog

## 16.340.0

- Opravena životnost debounce timeru při zavření hlavního okna.
- Opravena round-trip logika světlého, systémového a tmavého motivu.
- Zpřesněna smoke validace klávesové navigace a aktivace ovládacích prvků.
- Smoke validace changelogu nyní správně přijímá poslední vydanou verzi pod aktuální pracovní verzí.
- Zachována bezpečnostní ochrana power-plan hodnot AC `Never`.

## 16.339.0

- Zvětšen CPU Focus tray popup na `480×300`, aby se vešly celé popisy ventilátorů a režimu.
- Aktualizována placement a pixelová smoke validace pro nové rozměry při 1×, 2× a 3× DPI.
- Zachována brána ventilátorů pro Lian Li `0CF2:A102` a fallback pro nepodporovaný hardware.

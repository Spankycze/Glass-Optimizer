# Cursor packs

Bundled curated GitHub cursor packs: Bibata family by Kaiz Khatri (ful1e5)
and Bibata-derived authors, plus Modern Inverted by emvaized, Glass Glow by
MuseLinn, Vision Black by veax, Nailong by waverlose, Clawd Pixel by
xixicc186 and OpenZone by 0x414c / Davorin Ucakar.
